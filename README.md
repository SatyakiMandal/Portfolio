Live deployment: Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

---

## Overview

A high-performance executive portfolio and interactive case study platform featuring:
- **8 Primary Corporate Live Projects:** In-depth strategic breakdowns with interactive quantitative decision models, willingness-to-pay (WTP) curves, and empirical exhibits (Tata Steel, Tata Consumer Products, Campus Activewear, Hindustan Unilever, XLRI Alumni Policy, 1001 Stories, Ajooni Biotech, Arthdex).
- **10 National Case Competition Placements:** Podium and national finalist submissions (Zerodha TENET 2026, Maruti Suzuki Xcelerate, Galderma, TVS Credit, Hero Campus Challenge, etc.).
- **Executive Audit HUD & Command Palette:** Quick-access Recruiter Audit Matrix (`Ctrl+K` / `⌘K`) and downloadable Executive Briefs.
- **Dynamic Continuous Vertical Timeline:** Context-aware scroll-spy navigation with real-time per-node theme inversion.
- **Camera Roll & Analog Filmstrip:** Curated documentary photography and fine art sketches in an analog 35mm film reel interface.

---

## Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation & 3D:** [Framer Motion](https://www.framer.com/motion/) & HTML5 Canvas Particle Engine
- **Icons:** [@phosphor-icons/react](https://phosphoricons.com/)
- **Audit & Security:** Custom pre-build redaction & security auditing suite

## Getting Started

```bash
# Install dependencies
npm install

# Run security & redaction audit
npm run audit:redaction

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Production Build & Deployment

```bash
# Optimized production static build
npm run build

# Start production server
npm run start
```

### Deploy to Vercel

The application is pre-configured for instant zero-configuration deployment on [Vercel](https://vercel.com):
1. Import this repository in Vercel.
2. Framework preset will automatically be detected as **Next.js**.
3. Deploy!
